# osrs-tcg-expected-packs
Web Tool that shows how many packs you are expected to open and how many points you are expected to spend before you obtain a given card on OSRS TCG Plugin.

Feel free to use code and data present in this repository for whatever you want.

Run "extract_from_indexeddb.py" first to generate "catalog.json"

Then run "calculate_chances.py" to generate "calculated.json"
